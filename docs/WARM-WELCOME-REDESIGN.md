# PawVerdi warm-welcome redesign — November 11, 2026

## Scope
Refresh four public-facing pages: home, dog center, cat center and shop. Existing content, hero art, routes, affiliate labels and shop data remain intact.

## Visual direction
- More welcoming copy and accessible pathways into the site
- Three photographic editorial discovery cards per page, using existing PawVerdi images
- Gold accents, layered dark-green backgrounds, clearer action labels, generous spacing, responsive three-to-one-column layout
- Decorative photos have empty alt text because the linked card has full accessible text
- Hover motion respects reduced-motion preferences
- No external image downloads, new analytics, tracking scripts, or products
